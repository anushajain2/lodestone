# Legacy: the first prototype (computed dielectrics)

The first version of this project searched Materials Project *computed* data for high-k, wide-gap dielectrics, with simulated labs. It was replaced by the HTEM version (real measured thin films, lab replay) because a lab customer needs a loop over its own experiments, not a database screen.

This folder keeps that code, its tests and data for reference. It is not installed or tested, and its extra dependencies (matminer, pymatgen, mp-api, MACE) were removed from the project. Delete it whenever you like; git history has it too.
